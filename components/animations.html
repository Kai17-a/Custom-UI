Animations

操作に応じて自動で動くコンポーネントと、処理中のアニメーション。追加指定は不要です。

開く・閉じる・通知

表示時のフェードと閉じる動きを確認できます。閉じる操作・フォーカス・イベントは即座に反映します。

詳細を表示しました。続けて開閉しても、最新の操作が反映されます。

アニメーションを確認

閉じるボタン・Escapeで閉じます。

切り替え・コピー・選択

タブを切り替えると、内容と選択状態が滑らかに変化します。
キー操作でも同じ動きになります。フォーカス移動は待たせません。
アコーディオンを開閉する

内容の表示と非表示にも短いアニメーションが付きます。

自動アニメーションの対象

操作動きとサンプル
開く・閉じるモーダル・トースト・アラート・ヒント・日付ポップアップのフェード。
開閉・切り替えサイドバーの表示、アコーディオン、タブ・ページ送りの切り替え。
移動・日付選択カンバンのカード移動、カレンダーの月切り替えと日付選択。
入力・操作結果ボタンを押したとき、スイッチ・チェック・入力エラー、コピー成功のチェック。
処理・デザイン変更進捗バー・ローディングの更新、明暗・デザインテーマの切り替え。

動きは短く統一しています。アプリでは共通のui.css / ui.jsを使うだけで適用され、アニメーション用の属性は不要です。OSの「動きを減らす」設定では移動・フェードを止め、状態をすぐに切り替えます。

使用ファイル・取り込み方

共通の ui.css と ui.js を読み込み、サンプルのHTMLを配置します。必要な動作は data-ui-* 属性で指定します。

<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js / 属性一覧と導入例

assetsフォルダごとコピーするとCSS内の相対参照も維持できます。catalog.js、catalog-demo.js、layout.css はカタログ専用です。data-demo-* はアプリに取り込む際に外し、保存や通信はアプリ側で実装してください。
