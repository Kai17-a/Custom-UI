Getting started

classで見た目を、data-ui-*属性で動作を指定します。専用の初期化コードは通常不要です。

1. assetsフォルダをコピーする

ui.css は同じフォルダ内のCSSを相対参照します。assetsフォルダの構造を保ってコピーしてください。npm・ビルド・CDN・サーバーは不要です。

2. 共通2ファイルを読み込む

<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

scriptにはdeferを付けます。ライト／ダーク切替は data-ui-toggle="theme" のボタンで利用できます。

余白をクラスで指定する

sp-p-6 で内側24px相当、sp-mt-8 で上側の外余白32px相当、sp-gap-4 で要素間16px相当を指定できます。md:sp-p-6 は768px以上、lg:sp-p-8 は1024px以上で有効です。ui.cssだけで動作し、npmは不要です。従来のgap-3・px-3などは変更していません。

テーマを最初の描画から適用する

ダークテーマでページを移動する際の白いちらつきを防ぐには、次の処理をhead内のCSS読み込みより前に配置します。このカタログとstarter.htmlには設定済みです。保存した明暗とデザインを先に復元し、保存が使えない場合はOSの明暗設定を使います。デザインの復元にはbodyのdata-ui-theme-persistが必要です。bodyに直接指定したdata-ui-themeは優先されます。

<!-- Apply the saved theme before stylesheets or deferred UI scripts can paint. -->
<style>
html { background:var(--bs-body-bg, #faf9f7); color-scheme:light; }
html[data-bs-theme="dark"] { background:var(--bs-body-bg, #1b1c1e); color-scheme:dark; }
</style>
<script>
(() => {
  let mode = null, design = null;
  try { mode = localStorage.getItem('orchtop-theme'); } catch { /* Storage is optional. */ }
  try { design = localStorage.getItem('orchtop-design-theme'); } catch { /* Storage is optional. */ }
  const selected = ['light','dark','system'].includes(mode) ? mode : 'system';
  document.documentElement.dataset.uiColorPreference = selected;
  document.documentElement.dataset.bsTheme = selected === 'system'
    ? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light') : selected;
  if (!['default','glass','glassmorphism','flat','soft'].includes(design)) return;
  const restore = () => {
    if (!document.body) return false;
    if (document.body.hasAttribute('data-ui-theme-persist') && !document.body.hasAttribute('data-ui-theme')) {
      document.body.dataset.uiTheme = design;
    }
    return true;
  };
  if (!restore()) {
    const observer = new MutationObserver(() => { if (restore()) observer.disconnect(); });
    observer.observe(document.documentElement, {childList:true, subtree:true});
  }
})();
</script>

属性一覧

属性動作
data-ui-dismiss="alert"いちばん近い .alert を閉じます。固有IDは不要です。
data-ui-toggle="show" / "hide" / "collapse"data-ui-targetの領域を表示・非表示・切り替えます。
data-ui-toggle="sidebar"サイドバーを開閉し、aria-expandedと .app-shell のレイアウトを同期します。
data-ui-label-open / data-ui-label-closed開閉ボタンの表示文字を切り替えます。省略すると文字は変更しません。
data-ui-toggle="dialog" / data-ui-dismiss="dialog"ネイティブdialogの開閉。開くボタンにはdata-ui-targetを指定します。
data-ui-backdrop="static"dialogの外側クリックで閉じる動作を止めます。Escapeは利用できます。
data-ui-tooltip="説明文"ホバー・フォーカス・クリックで説明を表示。Escape・領域外クリックで閉じます。
data-ui-toast="文言"押すとトーストを表示します。data-ui-variantはsuccess / danger / info / warning。
data-ui-title / data-ui-body / data-ui-metaトーストのタイトル・本文・補足を指定します。本文は従来のdata-ui-toastにも指定できます。標準幅360pxで長文を折り返します。
data-ui-duration="6000"トーストの表示時間（ms）。0は自動消去なし。エラーの標準は0、その他は6000ms。操作中は消去を止めます。
data-ui-tabs / data-ui-panel="名前"タブの状態をグループ内に限定します。同じ名前を別グループでも使用できます。
data-ui-validate / data-ui-field / data-ui-error標準HTML制約で検証します。data-ui-messageでエラー文言を指定できます。
data-ui-pagination / data-ui-page-size="8"data-ui-page-itemを分割表示します。data-ui-pageとdata-ui-page-stepで移動、data-ui-page-statusで件数表示。
data-ui-board / data-ui-column="状態"HTMLのカンバン。data-ui-cardをドラッグ、またはdata-ui-moveのselectで移動します。
data-ui-target="#任意のID"別の要素を参照します。IDは利用側で自由に決め、ページ内で重複させないでください。
data-ui-focus="#任意のID"閉じる際のフォーカス移動先を明示できます。通常は関連ボタンまたは近くの操作へ戻ります。

アプリの処理と組み合わせる

共通UIは表示や操作だけを担当します。フォームは入力が有効なら通常のsubmitを続けます。保存・送信先・通信・ページ遷移はアプリ側で指定してください。カンバンの移動はページ内のDOMのみを更新します。

ui:valid（キャンセル可能）、ui:tabchange、ui:pagechange、ui:move、ui:shown、ui:hiddenのイベントでアプリの処理を接続できます。

document.addEventListener('ui:valid', event => {
  // 通常のフォーム送信を止め、自分の保存処理を呼びます。
  event.preventDefault();
  const values = new FormData(event.target);
  // saveProject(values);
});

document.addEventListener('ui:move', event => {
  const { card, from, to } = event.detail;
  // persistMove(card.dataset.uiCard, from, to);
});

OrchtopUI.toast({
  title: '保存しました',
  body: 'プロジェクトの変更を保存しました。',
  meta: 'たった今',
  variant: 'success'
});
// 従来の文字列形式も利用できます。
OrchtopUI.toast('保存しました。', { variant: 'success' });
OrchtopUI.show('#my-dialog');
OrchtopUI.hide('#help-panel');

// 動的に追加したHTMLのARIA・初期表示を整える場合：
OrchtopUI.init(container);

initは繰り返し実行できます。操作のイベントは委譲しているため、後から追加したボタンも動作します。
