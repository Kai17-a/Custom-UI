クラスで使う定番アニメーション

ui-animateと効果のクラスを1つ指定します。CSSだけで動き、標準は600ms・1回です。各サンプルの「再生する」で、必要な動きだけを確認できます。

<div class="ui-card ui-animate ui-animate-fade-in">
  <div class="ui-card-body">フェードで表示します</div>
</div>

速さ・遅延・繰り返し・一時停止

クラス動作
ui-animate-fast / ui-animate-slow300ms / 1200ms
ui-animate-delay-200 / ui-animate-delay-500開始を200ms / 500ms遅らせる
ui-animate-repeat繰り返す。表示し続ける場合は停止操作も用意してください。
ui-animate-paused一時停止する。クラスを外すと続きから再開する
<span class="fx-inline ui-animate ui-animate-bounce ui-animate-slow ui-animate-delay-200">お知らせ</span>
<div class="ui-animate ui-animate-float ui-animate-slow ui-animate-repeat">…</div>

フェードアウト・ズームアウトは終了後も透明になります。表示の切り替え、DOMの削除、操作対象から外す処理はアプリ側で行ってください。文字に移動・拡大・回転を付ける場合はfx-inlineを併用してください。既存のスピナーなどに追加する場合は、外側の要素に指定すると、それぞれの動きを保てます。

速度は--ui-animation-duration、遅延は--ui-animation-delayでも調整できます。OSの「動きを減らす」が有効な場合、これらの動きは停止し、内容はすぐ表示されます。

使用ファイル・取り込み方

共通の ui.css と ui.js を読み込み、サンプルのHTMLを配置します。必要な動作は data-ui-* 属性で指定します。

<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js / 属性一覧と導入例

assetsフォルダごとコピーするとCSS内の相対参照も維持できます。catalog.js、catalog-navigation.js、catalog-demo.js、layout.css はカタログ専用です。data-demo-* はアプリに取り込む際に外し、保存や通信はアプリ側で実装してください。
