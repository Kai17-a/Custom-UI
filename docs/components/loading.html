サイズ・色

標準のui-spinnerは20pxです。サイズを変える場合は、ui-spinner-xs（12px）・ui-spinner-sm（16px）・ui-spinner-lg（32px）・ui-spinner-xl（48px）を使います。

スケルトンシマー

読み込み後の形を示すプレースホルダーです。skeletonにskeleton-shimmerを追加すると、光が左から右へ流れます。

タスクを読み込み中…

skeletonだけなら静止表示です。シマーはJavaScript不要で動作し、動きを減らすOS設定では静止表示になります。

カード・画像・アバターのシマー

記事とプロフィールを読み込み中…

見出しはskeleton-title、円形はskeleton-circle、画像枠はskeleton-mediaを併用します。円のサイズは--skeleton-size、横幅はwidthで調整できます。

取得完了後はプレースホルダーを実際の内容に置き換え、aria-hiddenを外し、親のaria-busyをfalseにします。読み込み結果を伝えるrole="status"は、その領域の外で更新してください。

ボタン内のローディング

ui-loading-buttonにaria-busy="true"とdisabledを付けます。処理中の再クリックを防ぎ、元の文字は読み上げ名として残します。

保存中… ボタンの幅を保ったまま、ラベルをスピナーに切り替えます。

アイコンボタン

アプリとの連携

見た目は共通のui.cssとHTMLだけで利用できます。共通ui.jsのKavUI.loading(要素またはセレクター, true / false)を使うと、aria-busyとボタンのdisabledをまとめて切り替え、終了時に開始前の状態へ戻します。通信や進捗の更新はアプリ側で行います。

// ui-loading-buttonのHTMLを配置した後、アプリの処理から呼びます。
async function save(button, values) {
  if (button.disabled) return;
  KavUI.loading(button, true);
  try {
    await saveProject(values); // 自分の保存処理
    KavUI.toast({ title: '保存しました', variant: 'success' });
  } catch {
    KavUI.toast({ title: '保存できませんでした', body: '再試行してください。', variant: 'danger' });
  } finally {
    KavUI.loading(button, false);
  }
}

// 要素の代わりにセレクターも指定できます。
KavUI.loading('#save-button', true);
KavUI.loading('#save-button', false);

// progressは通常のDOM APIで更新できます。
progressElement.value = 60;
// 不明な進捗に切り替える場合：
progressElement.removeAttribute('value');

ボーダーのあるパネルにも同じAPIを使えます。APIと直接の属性操作は同じ処理内で混在させず、対応するtrue / falseを1組で呼んでください。

スピナーは装飾としてaria-hiddenにし、読み込み状況を文字で示します。結果を読み上げるrole="status"は、aria-busyを付けた領域の外に置いてください。動きを減らすOS設定では回転・移動を止め、文字や静止した枠線で状態を示します。

使用ファイル・取り込み方
<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

npmは不要です。assetsフォルダの構造を維持してコピーしてください。
