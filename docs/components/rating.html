Kav-UI / DESIGN SYSTEM

Rating

星で評価を入力・表示するコンポーネント。ネイティブのradioを使い、フォーム送信・リセット・キーボード操作に対応します。

評価入力とリセット

標準のradioを使うため、フォーム送信・キーボード・リセットがそのまま動きます。同じ評価の星には同じnameを指定し、別の評価には別名を使います。

使いやすさ

サイズと色

ui-rating-sm・ui-rating-lgでサイズ、ui-rating-warningで警告色の星にできます。

使いやすさ
使いやすさ

操作を無効にする

グループ全体にはfieldsetのdisabledを使います。個別の星にも標準のdisabledを使えます。

使いやすさ

表示専用

入力を伴わない評価はui-rating-staticで表示し、読み上げ名に値を含めます。

4.0 / 5

値の取り出しと参考

const form = document.getElementById('rating-form');
const rating = new FormData(form).get('rating');

JavaScriptは不要です。機能の参考：daisyUI Rating。星のSVGは既存のMDIを使い、同梱のライセンスに従います。

使用ファイル・取り込み方
<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js。Vue・Astroでは既存のKavWidgetに同じHTMLを渡して利用できます。パッケージの使い方も参照してください。
