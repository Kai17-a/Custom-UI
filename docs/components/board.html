状態と色の対応

確認待ちは人の注意が必要な状態なので warning 系で統一します。完了は緑の輪、確認待ちは warning の塗りの丸で区別します。印は装飾なので、状態名も文字で添えてください。

ボード・エージェント図・推奨バッジの状態対応
状態ボードの印エージェント図のノード推奨する状態バッジ
未着手dot-todo：secondary-color の輪data-state="pending"：secondary-color の状態文字と輪、標準の枠text-bg-secondary
進行中dot-in_progress：primary の半塗りの丸data-state="running"：primary の枠、primary-text-emphasis の状態文字と塗りの丸text-bg-primary
確認待ちdot-review：warning の枠と塗りの丸data-state="review"：warning の枠、warning-text-emphasis の状態文字text-bg-warning
完了dot-done：success の輪（中は空）data-state="complete"：success-text-emphasis の状態文字と塗りの丸、標準の枠text-bg-success
止まっているなしdata-state="blocked"：danger-text-emphasis の状態文字と輪、標準の枠text-bg-danger

色名は既存の --bs-* トークンを指します。ボードに停止状態の印はありません。5テーマのライト・ダークで、確認待ちの印の外周は列・カードの背景に対して3:1以上のコントラストを確保します。

使用ファイル・取り込み方

共通の ui.css と ui.js を読み込み、サンプルのHTMLを配置します。必要な動作は data-ui-* 属性で指定します。

<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js / 属性一覧と導入例

assetsフォルダごとコピーするとCSS内の相対参照も維持できます。catalog.js、catalog-navigation.js、catalog-demo.js、layout.css はカタログ専用です。data-demo-* はアプリに取り込む際に外し、保存や通信はアプリ側で実装してください。

ui.js はHTML上のカードを移動し、ui:move イベントを発行します。データの保存や通信はアプリ側で実装してください。
