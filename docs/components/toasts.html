Kav-UI / DESIGN SYSTEM

Toasts & alerts

標準幅は360px。長いタイトル・本文・URLは折り返し、狭い画面では画面幅に収めます。タイトル・本文・補足を属性またはJavaScriptで指定できます。

本文だけの通知（従来の書き方）

画面内に置くアラート

Saved.
Something went wrong, so it stays until it is closed.

タイトル＋本文＋補足

通知の内容を次の属性で指定します。必要な項目だけ設定できます。

  • data-ui-title：タイトル
  • data-ui-body：本文
  • data-ui-meta：日時などの補足

成功・情報・警告・エラー

data-ui-variantにsuccess・info・warning・dangerを指定して、通知の意味に合う色を選びます。

長文・改行・長いURLの折り返し

タイトルだけ・本文だけ

表示時間を指定する

data-ui-durationで表示時間をミリ秒単位で指定します。10000なら10秒、0なら閉じるまで表示します。

標準は6秒、エラーは自動消去なしです。マウスが重なっている間と、閉じるボタンにフォーカスしている間は消去を止めます。

コピーアイコンを付ける（任意）

data-ui-toast-copyを追加すると、トーストの本文末尾に、文字と同じサイズのコピーアイコンを表示します。タイトルだけの通知ではタイトル末尾に付き、タイトルをコピーします。長いメッセージでは文末の文字と一緒に折り返し、アイコンだけの行になるのを防ぎます。

data-ui-copy-textでコピー対象を、data-ui-copy-labelで読み上げ名・ホバー時の説明を変更できます。

成功時はチェックマークに切り替わり、2秒後に元に戻ります。コピー中・フォーカス中・マウスが重なっている間は自動消去を止めます。

KavUI.toast({
  title: '共有URL',
  body: 'https://example.test/projects/design-catalog',
  copy: true,
  duration: 0
});

KavUI.toast({
  title: '処理に失敗しました',
  body: 'エラーIDをお問い合わせ時にお伝えください。',
  variant: 'danger',
  copy: true,
  copyText: 'ERR-2026-001',
  copyLabel: 'エラーIDをコピー'
});

JavaScriptから表示

KavUI.toast({
  title: '保存しました',
  body: 'プロジェクトの変更を保存しました。',
  meta: 'たった今',
  variant: 'success',
  duration: 6000
});

// 従来の書き方も利用できます。
KavUI.toast('変更を保存しました。', { title: '保存完了' });

幅を変更する

全通知の幅はCSS変数で指定できます。スマートフォンでは左右16pxを確保し、高さは本文に合わせて伸びます。通知が画面の高さを超える場合は、通知領域をスクロールできます。

:root { --ui-toast-width: 420px; }
使用ファイル・取り込み方

共通の ui.css と ui.js を読み込み、サンプルのHTMLを配置します。必要な動作は data-ui-* 属性で指定します。

<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js / 属性一覧と導入例

assetsフォルダごとコピーするとCSS内の相対参照も維持できます。catalog.js、catalog-navigation.js、catalog-demo.js、layout.css はカタログ専用です。data-demo-* はアプリに取り込む際に外し、保存や通信はアプリ側で実装してください。
