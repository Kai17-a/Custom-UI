Sortable list

ドラッグ、タッチ、キーボードでリストを並べ替えます。保存や通信はアプリ側で実装してください。

Space または Enter で持ち上げ・確定、上下左右の矢印で移動、Escape で取り消します。ハンドルなしでは項目全体、ハンドル付きではハンドルからドラッグできます。タッチでページをスクロールする場合は、ハンドル付きリストの本文またはリスト外を使ってください。

  • 実装する
  • レビューする

  1. 下書きを作る
  2. 内容を確認する
  3. 公開する

API

属性・イベント
API動作
data-ui-sortableul / ol / div の直下の要素を並べ替えます。縦方向のリストに使用します。
data-ui-sortable-handle項目内の任意のハンドル。button type="button" と項目を識別できる名前を推奨します。省略時は項目自体がフォーカス可能になります。
ui:sortable-change順序が変わって確定したときに発行。detail は {item, from, to, order}。from / to は0始まり、item はDOM要素、order は並べ替え後のDOM要素の配列です。キャンセル・変更なしでは発行しません。
init(scope) / destroy(scope)既存の KavUI API で初期化と解除。パッケージの mount(root, {signal}) にも対応します。

項目の永続IDは data-id などでアプリ側が管理してください。日本語のライブ通知と操作説明を自動付与します。動きを減らす設定を尊重します。

使用ファイル・取り込み方

共通の ui.css と ui.js を読み込み、サンプルのHTMLを配置します。
