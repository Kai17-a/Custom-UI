ページの骨組みを、タグとクラスの組み合わせで作ります。既存の色・余白・角丸を引き継ぎ、すべてのデザインテーマとライト／ダークに対応します。npmは不要です。

PCを基本に、タブレット・スマートフォンへ対応

PCは1024px以上、タブレットは768px以上1024px未満、スマートフォンは768px未満です。端末名ではなくブラウザの表示幅で切り替えます。PCの見た目を通常のクラスで指定し、タブレットはtablet:、スマートフォンはmobile:で変更します。共通のui.cssだけで使えます。

プロジェクト

PCは3列、タブレットは2列、スマートフォンは1列です。

メンバー

アクティビティ

色・角丸・影は既存テーマを引き継ぎます。

tablet:はタブレット幅だけ、mobile:はスマートフォン幅だけに適用します。指定のない幅では通常クラスが適用されます。従来のmd:・lg:やfx-*-md-*は「その幅以上」の指定として引き続き使えます。同じプロパティでは端末別指定とmd/lg指定を混在させないでください。

Flexboxの方向・折り返し・整列・伸縮・列数・列幅、sp-*の余白、type-*の文字指定にプレフィックスを付けられます。例：mobile:fx-column、tablet:fx-col-6、mobile:sp-gap-2、tablet:type-size-xl。基本クラスの一覧はFlexbox・Flex grid・Spacing・Typographyを参照してください。

表示の切り替え・全幅・横スクロール

PCで表示しています。

タブレットで表示しています。

スマートフォンで表示しています。

ui-hidden・ui-block・ui-inline・ui-flex・ui-inline-flex・ui-gridで表示方法、ui-w-full・ui-w-autoで幅、ui-overflow-x-autoで横スクロールを指定できます。これらもtablet:・mobile:に対応します。HTMLのhidden属性は表示クラスでは解除されません。

横長の表はui-table-scrollで囲み、領域内をスクロールできるようにします。Tableのサンプル →。カンバンは既存のui-board-wrapで列構造を保ったまま横スクロールします。

<div class="ui-table-scroll" tabindex="0" role="region" aria-label="プロジェクト一覧（横スクロール可能）">
  <table class="table">…</table>
</div>

画像・動画・canvasはクラスなしでも親幅に収まり、縦横比を維持します。SVGも親幅を超えません。アプリのui-pageは利用できる領域幅でカラムを切り替えます。カタログの目次は本文幅を確保できる1280px以上で右側、それ未満では本文上部に表示します。目次はPC・タブレットでは表示され、スマートフォンでは必要なときに展開できます。

クラスの組み合わせ方

1カラムの基本形です。mainはページに1つだけ配置してください。カタログの例を本文内に埋め込む場合は、mainの代わりにdivやsectionを使います。

<body class="ui-app">
  <header class="ui-header ui-header-sticky">…</header>
  <main class="ui-app-main">
    <div class="ui-container ui-layout">
      <div class="ui-page">
        <div class="ui-page-body">…</div>
      </div>
    </div>
  </main>
  <footer class="ui-footer">…</footer>
</body>

ui-page-aside-stickyをasideに追加すると、横並びのときだけ追従します。上に固定ヘッダーがある場合は--ui-layout-offsetに実際のヘッダー高を指定してください。追従領域が長い場合は領域内をスクロールできます。固定が不要ならこれらのクラスは省略します。

余白はsp-*、整列はfx-*の既存ユーティリティを併用できます。カラムの切り替えにはCSS Container Queriesを使います。未対応ブラウザでは縦並びで表示されます。

使用ファイル・取り込み方

共通の ui.css と ui.js を読み込み、サンプルのHTMLを配置します。必要な動作は data-ui-* 属性で指定します。

<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js / 属性一覧と導入例

assetsフォルダごとコピーするとCSS内の相対参照も維持できます。catalog.js、catalog-navigation.js、catalog-demo.js、layout.css はカタログ専用です。data-demo-* はアプリに取り込む際に外し、保存や通信はアプリ側で実装してください。
