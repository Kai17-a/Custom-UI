Agent workflow

AIエージェントの処理手順、役割の階層、並列実行、タスクの内訳を可視化します。すべて架空の実行データです。接続線は丸い曲がり角でつなぎ、短い強調線が移動するボーダーチェイスで表示します。

AI Agent Workflow Visualization

左から右へ処理が進みます。スマートフォンでは上から下へ並びます。色に加えて文字で実行状態を示します。

  1. 完了要件を整理Planner · 対象と調査項目を確定
  2. 完了情報を集めるResearcher · 3つの資料を照合
  3. 実行中レポートを書くWriter · 調査結果を構成
  4. 待機中品質を確認Reviewer · 出典と結論を検証

Hierarchical Node Graph UI

親ノードの下に担当エージェントと子タスクを配置します。接続は上から下への委任を表します。狭い画面では図の領域を横にスクロールできます。

  • 実行中Coordinator調査プロジェクトを統括
    • 実行中Research agent資料の収集を担当
      • 完了出典を収集公式資料を3件確認
    • 待機中Writing agent原稿の作成を担当
      • 待機中構成案を作成調査結果の受け取り待ち

Agent Orchestration Graph

Coordinatorが3つの作業を並列に委任し、すべての結果をReviewerへ渡します。確認待ちのノードがあるため、レビューは開始していません。

  • 実行中Coordinator調査・実装・検証を委任
    • 完了ResearcherAPI仕様の調査
    • 実行中Builder連携処理を実装
    • 確認待ちTesterテスト用認証情報が必要
待機中Reviewer3つの結果を統合して検証

Interactive Task Tree

見出しで子タスクを開閉し、チェックで完了を切り替えます。Tabで移動し、EnterまたはSpaceで開閉、Spaceでチェックできます。

リリースの準備 — Coordinator
  • 調査 — Researcher
  • 実装 — Builder

変更はこのページ内だけに反映されます。開閉状態とチェック状態は独立しています。

取り込み方

共通の ui.css を読み込み、各例の「HTMLを表示」からマークアップをコピーします。ボーダーチェイスのアニメーションには共通の ui.js も読み込みます。追加ライブラリは不要です。JavaScriptなしでも静止した図を表示します。

<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>
  • ui-agent-flowing と data-ui-agent-flow：接続線のボーダーチェイス。ui-agent-motion 内のチェックで各図を停止・再開できます。画面外・非表示タブでは停止し、動きを減らす設定では静止します。速度は --ui-agent-flow-duration（既定2.8秒）で指定します。
  • ui-agent-flow：順番のある処理を ol で記述。
  • ui-agent-tree：役割の親子関係を ul / li の入れ子で記述。
  • ui-agent-tree-parallel と ui-agent-merge：高さを揃えた3分岐と合流先。直前の3ノード構成と組み合わせます。
  • data-state：complete / running / pending / blocked。状態の文字もHTMLで指定してください。進行中のステップは aria-current="step" で示せます。
  • ui-agent-tasks：details / summary と checkbox によるタスクツリー。アプリ側では標準の toggle / change イベントで処理を接続します。

図はHTMLに記述した状態を表示します。実際のエージェント実行・自動レイアウト・データ保存はアプリ側で実装してください。グラフを変更するときは、入れ子と説明文を実際の依存関係に合わせて更新します。
