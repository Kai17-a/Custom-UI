Kav-UI / DESIGN SYSTEM

Command menu

検索からページや操作を選ぶメニュー。インライン・ダイアログ・キーボード選択・グループ・空結果に対応します。

検索して操作を選ぶ

data-ui-commandに検索欄と操作一覧を配置します。ラベルとdata-ui-keywordsを部分一致で検索でき、全角英数字にも対応します。

ページ

操作

一致する操作がありません。別の言葉で検索してください。

↑↓ 選択・Enter 実行

操作を選ぶと、ここに結果を表示します。

ダイアログとショートカット

通常のダイアログ属性と組み合わせます。data-ui-command-shortcut="k"を付けた場合だけ、Ctrl／⌘＋Kで開閉できます。外側の入力欄で編集中はショートカットを奪いません。

ページ

操作

一致する操作がありません。別の言葉で検索してください。

↑↓ 選択・Enter 実行

操作を選ぶと、ここに結果を表示します。

キーボード・無効項目・空結果

  • ↑↓で操作を選び、Enterで実行します。IMEでの変換確定では実行しません。
  • 無効な操作はdisabledまたはaria-disabled="true"で指定します。
  • 一致する項目がないときはdata-ui-command-emptyを表示します。
  • Escapeでダイアログを閉じて元の操作へ戻ります。インラインでは検索語を消します。

選択イベントと動的な更新

操作の実行処理はアプリ側で接続します。選択時にはui:commandselectが発火し、detail.valueとdetail.itemを取得できます。ボタンの通常のclickや、既存のトースト属性も利用できます。

const command = document.querySelector('[data-ui-command]');
command.addEventListener('ui:commandselect', event => {
  console.log(event.detail.value);
});

// 操作項目を追加した後
KavUI.init(command);
// DOM全体を作り直す前
KavUI.destroy(command);

機能の参考：shadcn/ui Command。表示と実装はKav-UI独自で、外部ライブラリは読み込みません。

使用ファイル・取り込み方
<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js。Vue・Astroでは既存のKavWidgetに同じHTMLを渡して利用できます。パッケージの使い方も参照してください。
