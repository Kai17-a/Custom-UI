Carousel

カードや機能紹介をスライドで表示。ボタン・インジケーター・キーボード・スワイプで、利用者が必要なタイミングで切り替えます。

前後の切り替えとインジケーター

ui-carousel-slideを横に並べます。前後ボタン、任意のスライドへの移動、現在位置の表示を属性で指定できます。自動再生はしません。

FEATURE 1

プロジェクト管理

タスクや資料をまとめ、必要な情報をすぐに見つけます。

FEATURE 2

進捗の可視化

チームの作業状況をチャートと一覧で確認できます。

FEATURE 3

チームで共有

変更履歴を残しながら、プロジェクトの情報を共有します。

1 / 3

ループと初期位置

data-ui-carousel-loopで端から反対側へ移動できます。data-ui-carousel-indexは0始まりの初期位置です。この例は2枚目から開きます。

1 / 3

キーボード・タッチ・動きを減らす設定

  • スライド領域にTabで移動し、←→で前後、Home／Endで最初／最後へ移動します。RTLでは左右の方向を合わせます。
  • スマートフォンはネイティブの横スクロールでスワイプできます。
  • 表示していないスライドの操作はフォーカス対象から外します。
  • OSで動きを減らしている場合は、ボタンの移動もアニメーションせず切り替えます。

画像・イベント・破棄

スライドには画像、説明、フォームやカードなどを配置できます。選択が変わるとui:carouselchangeが発火し、0始まりのdetail.indexとdetail.totalを取得できます。

<section class="ui-carousel-slide">
  <img src="feature.jpg" alt="プロジェクトの作業一覧">
</section>

<!-- スライドを追加した後はKavUI.init(root)で更新。
     作り直す前はKavUI.destroy(root)で後始末します。 -->
const carousel = document.querySelector('[data-ui-carousel]');
carousel.addEventListener('ui:carouselchange', event => {
  console.log(event.detail.index, event.detail.total);
});

// スライドを追加した後
KavUI.init(carousel);
// DOM全体を作り直す前
KavUI.destroy(carousel);

JavaScriptがない場合も横スクロールで内容を確認できます。機能の参考：Bootstrap Carousel、操作とARIAの参考：WAI-ARIA Carousel Pattern。

使用ファイル・取り込み方
<link rel="stylesheet" href="assets/css/ui.css">
<script defer src="assets/js/ui.js"></script>

ui.css / ui.js。Vue・Astroでは既存のKavWidgetに同じHTMLを渡して利用できます。パッケージの使い方も参照してください。
