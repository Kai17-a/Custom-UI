MDI icons

Material Design Icons（MDI）を使用しています。 MDI 7.4.47のSVGを同梱しています（Apache License 2.0）。出典・同梱ファイルを確認する

よく使うMaterial Design Iconsを128種類収録しています。SVGの中身をコピーしてHTMLに貼り付けるだけで使えます。import・アイコンフォント・CDN・スプライトは不要です。

サイズ・色・組み合わせの見本 → / サイドバーでの使い方 →

属性でアイコンを指定する

共通のui.cssとui.jsを読み込むと、icon="mdi-home"のように名前だけで表示できます。同梱128種類に対応し、外部通信・追加ファイルの読み込みは不要です。SVGを直接貼り付ける場合はJavaScriptも不要です。

標準サイズは周囲の文字と同じ1emです。ui-icon-sm / md / lg / xlで16 / 24 / 32 / 48pxを指定できます。任意のサイズは--ui-icon-sizeで調整できます。色は文字色を引き継ぎます。サイドバーにはclass="sidebar-icon"を併用できます。

属性はspan・i・button・aなど、子要素を配置できるHTML要素に指定してください。子要素の先頭に装飾用SVGを挿入し、既存の文字やイベントは維持します。アイコンだけのボタンにはボタンのaria-labelを指定します。単体のアイコンに意味を持たせる場合は、上のホームの例のように要素へrole="img" aria-label="説明"を指定してください。

追加した要素とicon属性の変更は自動で反映します。KavUI.init(element)でも初期化できます。存在しない名前や属性の削除では生成SVGを取り除き、既存の文字・代替表示を維持します。

const icon = document.querySelector("[icon]");
icon.setAttribute("icon", "mdi-star");
