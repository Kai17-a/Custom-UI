Kav-UI / GETTING STARTED

ダウンロード・導入

CSS・JavaScriptをダウンロードし、アプリのHTMLから読み込むまでの手順です。HTML版はnpmやビルドなしで利用できます。

  1. ZIPをダウンロードして展開します。
  2. assetsフォルダをアプリへコピーします。
  3. HTMLでui.cssとui.jsを読み込みます。

1. CSS・JavaScriptをダウンロード

ソースZIPから入手する

GitHubのソースZIPには、CSS・JavaScriptを含むassetsフォルダが入っています。次のリンクでmainブランチのZIPをダウンロードできます。

ソースZIPをダウンロード GitHubを開く

  1. ZIPを展開します。
  2. 展開したCustom-UI-mainフォルダを開きます。
  3. 中のassetsフォルダを、次の手順でアプリへコピーします。

ソースZIPはmainブランチの内容です。作業中の未マージの変更は含まれません。GitHub画面から入手する場合は「Code」→「Download ZIP」を選びます。

Release ZIPが公開されている場合

GitHub Releasesの対象バージョンを開き、「Assets」からkav-ui-vX.Y.Z.zipをダウンロードします。展開したkav-ui/assetsフォルダを使います。vX.Y.Zはバージョンの表記例です。

Releaseがまだない場合や、必要なZIPが見つからない場合は、上のソースZIPから導入できます。libraries-v...のリリースにある.tgzはVue・Astro向けのパッケージです。HTML版はkav-ui-vX.Y.Z.zipを選びます。

2. assetsフォルダを配置

アプリの公開ディレクトリへassetsフォルダをコピーします。HTMLと同じ階層に置く場合は、次の構成になります。

my-app/
  index.html
  assets/
    css/
      ui.css
      tokens.css
      components/...
      ...
    js/
      ui.js
      theme-init.js
    icons/mdi/...
    vendor/material-color-utilities/...

ui.cssは同じフォルダやcomponents内のCSSを読み込みます。cssフォルダは中身と階層を保ったままコピーしてください。HTMLで指定するCSSはui.cssの1つで構いません。

ファイル役割
assets/css/一式文字・色・余白・全コンポーネントのスタイル
assets/js/ui.jsモーダル・通知・選択パネルなどの操作。MDIのSVGと配色の処理も同梱
assets/js/theme-init.js任意。保存したテーマをCSSの読み込み前に復元
assets/icons/mdi/・assets/vendor/アイコンや外部コードのライセンス・クレジット。再配布時も保持

サーバーを使うアプリでは、ブラウザからアクセスできる公開フォルダへ配置します。既存のassetsと分けたい場合は、vendor/kav-ui/assetsなどへ置き、読み込み先のパスを合わせてください。

3. HTMLから読み込む

次のHTMLをindex.htmlとして保存してください。ui.cssで見た目を読み込み、defer付きのui.jsでHTMLの準備後に操作を初期化します。通常は自分でKavUI.init()を呼ぶ必要はありません。

<!doctype html>
<html lang="ja" data-bs-theme="light">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Kav-UIを使う</title>
  <link rel="stylesheet" href="assets/css/ui.css">
  <script defer src="assets/js/ui.js"></script>
</head>
<body>
  <main class="ui-container sp-py-6">
    <h1 class="type-title">Kav-UIを使う</h1>
    <p>classとdata属性で使えるUIフレームワークです。</p>
    <button type="button" class="btn btn-primary"
      data-ui-toast="CSSとJavaScriptを読み込めました。">
      通知を表示
    </button>
  </main>
</body>
</html>

classで見た目を、data-ui-*属性で操作を指定します。CSSのみで使える文字・余白・カードなどは、JavaScriptを読み込まなくても表示できます。属性一覧とコンポーネントの使い方も参照してください。

4. 表示と動作を確認

  1. 作成したindex.htmlをブラウザで開きます。
  2. 余白や文字・ボタンのデザインが反映されていることを確認します。
  3. 「通知を表示」を押して、トーストが表示されれば読み込み完了です。

カタログ内の動く最小サンプルを開く / コンポーネントを探す

各コンポーネントページの「HTMLを表示」から必要なHTMLをコピーできます。アプリではdata-demo-*属性を外し、保存・送信・ページ遷移などの処理を接続してください。

保存済みテーマを初回表示から適用する

テーマを保存して使う場合は、theme-init.jsをCSSより前に読み込み、bodyにdata-ui-theme-persistを付けます。このスクリプトは同期で動くため、deferを付けずに配置します。

<head>
  <!-- metaなどの設定 -->
  <script src="assets/js/theme-init.js"></script>
  <link rel="stylesheet" href="assets/css/ui.css">
  <script defer src="assets/js/ui.js"></script>
</head>
<body data-ui-theme-persist>
  <!-- アプリの内容 -->
</body>

ライト・ダーク・システムの切り替え、ガラスなどのデザインテーマ、配色の選択を組み合わせられます。

表示・操作が反映されない場合

標準のHTMLの見た目になる
ui.cssのパスと、参照されるCSS一式が揃っているか確認してください。ブラウザの開発者ツールのNetworkで404になっているCSSを確認できます。
ボタンを押しても通知やモーダルが開かない
ui.jsの読み込み先とdeferを確認し、各ページのdata-ui-*属性もコピーしてください。スクリプトの読み込みはページ内で1回にします。
別フォルダのHTMLだけ表示が崩れる
相対パスはHTMLの場所が基準です。例えばpages/settings.htmlから上の構成のCSSを読む場合は../assets/css/ui.cssを指定します。
サンプルとアプリの動作が違う
カタログ用のcatalog.js・catalog-demo.js・layout.cssは読み込まず、共通のui.cssとui.jsを使ってください。サンプルのdata-demo-*は見本画面専用です。

バージョンを更新する

新しいZIPを展開し、使用中のCSS・JSを同じバージョンのファイル一式へ入れ替えます。アプリ独自の変更は別のCSSにまとめておくと、更新時に保ちやすくなります。

Releaseにkav-ui-vX.Y.Z.zip.sha256がある場合は、ZIPと同じフォルダへ保存して照合できます。

sha256sum --check kav-ui-vX.Y.Z.zip.sha256

Vue・Astro向けのパッケージで使う場合は、パッケージの導入手順を参照してください。
