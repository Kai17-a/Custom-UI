Kav-UI / UI TOOLKIT

Getting started

Kav-UIはclassで見た目を、data-ui-*属性で動作を指定する共通UIです。専用の初期化コードは通常不要です。JavaScriptから操作する場合はKavUIを使用します。

CSS・JavaScriptのダウンロードと導入手順

検索・ソート付きのデータテーブル

Data tableは、HTMLの行に検索・文字/数値/日付ソート・ページ送り・行選択を追加する部品です。親にdata-ui-data-table、列名のbuttonにdata-ui-table-sortを指定します。

カラーパレット

ユーザーが基準色と彩度を選べるカスタム配色フォームも利用できます。formにdata-ui-palette-editor、色入力にdata-ui-palette-seed、彩度入力にdata-ui-palette-chromaを指定します。APIはKavUI.setCustomPalette()です。初回描画前の復元には、CSSより前に任意のassets/js/theme-init.jsを読み込みます。

Material 3に基づく6種類の低彩度パレットを追加しています。htmlにdata-ui-palette="sage"を付けると、CSSだけで全体に反映します。切り替え部品はdata-ui-palette-select、ボタンはdata-ui-palette-value="sage"、APIはKavUI.setPalette()です。質感のdata-ui-theme、明暗のdata-bs-themeとは独立します。

領域のサイズ変更

Splitterは、横・縦のパネルをドラッグやキーボードで調整する部品です。親にdata-ui-splitter、直下のパネルにdata-ui-splitter-panelを指定します。最小／最大サイズ・折り畳み・入れ子・任意保存に対応し、APIはKavUI.splitter()です。

ガラスの背景画像

glass・glassmorphismには任意の背景画像を指定できます。CSSクラスで--ui-theme-background-imageと--ui-theme-background-opacityを設定するだけで、画像を薄く重ねます。指定しなければ従来の背景を維持します。設定方法とプレビュー →

サービス画面・チャート

サービステンプレートは、ドキュメント・ダッシュボード・changelog・エラー画面の独立したHTMLです。画面固有のtemplates.css / templates.jsと共通のui.css / ui.jsで動きます。

Chartは共通UIに含まれ、data-ui-chart属性とJSONで折れ線・面・棒・ドーナツを描画できます。データ表も自動で付きます。更新はKavUI.chart(element, config)を使います。

スムーズスクロール

ページ全体またはスクロール領域にui-scroll-smoothを付けます。data-ui-scroll-activeを付けた領域は、aria-currentの項目が見える位置まで移動します。使用例・固定ヘッダーの余白・動きを減らす設定を参照してください。

検索・スライド・履歴・評価

Command menuで操作を検索し、Carouselで内容をスライド表示できます。Timelineは履歴、Ratingは星による評価入力です。共通のui.css / ui.jsで使え、TimelineとRatingの基本表示にはJavaScriptも不要です。

メニュー・パネル・連結コンポーネント

追加の汎用コンポーネントも共通のui.cssとui.jsだけで使えます。Dropdown・PopoverはPopover API、Drawerはdialogを使用します。Input group・Button group・List group・Avatarの見た目にはJavaScriptは不要です。

  • Dropdown：操作メニュー・上下配置・キーボード・選択イベント
  • Popover：操作を含む補足パネル・フォーム・画面端補正
  • Drawer：左右上下のサイドパネル・背景スクロール停止・フォーカス復帰
  • Input group：入力欄と接頭辞・接尾辞・ボタン・selectの連結
  • Button group：ボタンの連結・縦並び・radio／checkboxの選択
  • List group：一覧・操作・現在地・件数・チェック付きリスト
  • Avatar：イニシャル・画像・サイズ・ステータス・グループ

追加対象の参考：BootstrapのDropdown・Offcanvas・Input group、BulmaのDropdown、daisyUIのAvatar。コードと見た目はKav-UIの構成に合わせて実装しています。

テーマを最初の描画から適用する

ダークテーマでページを移動する際の白いちらつきを防ぐには、次の処理をhead内のCSS読み込みより前に配置します。このカタログとstarter.htmlには設定済みです。保存した明暗とデザインを先に復元し、保存が使えない場合はOSの明暗設定を使います。デザインの復元にはbodyのdata-ui-theme-persistが必要です。bodyに直接指定したdata-ui-themeは優先されます。

<!-- Apply the saved theme before stylesheets or deferred UI scripts can paint. -->
<style>
html { background:var(--bs-body-bg, #faf9f7); color-scheme:light; }
html[data-bs-theme="dark"] { background:var(--bs-body-bg, #1b1c1e); color-scheme:dark; }
</style>
<script>
(() => {
  let mode = null, design = null, palette = null;
  try { mode = localStorage.getItem('kav-ui-theme'); } catch { /* Storage is optional. */ }
  try { design = localStorage.getItem('kav-ui-design-theme'); } catch { /* Storage is optional. */ }
  const selected = ['light','dark','system'].includes(mode) ? mode : 'system';
  document.documentElement.dataset.uiColorPreference = selected;
  document.documentElement.dataset.bsTheme = selected === 'system'
    ? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light') : selected;
  if (!['default','glass','glassmorphism','flat','soft'].includes(design)) return;
  const restore = () => {
    if (!document.body) return false;
    if (document.body.hasAttribute('data-ui-theme-persist') && !document.body.hasAttribute('data-ui-theme')) {
      document.body.dataset.uiTheme = design;
    }
    return true;
  };
  if (!restore()) {
    const observer = new MutationObserver(() => { if (restore()) observer.disconnect(); });
    observer.observe(document.documentElement, {childList:true, subtree:true});
  }
})();
</script>

アプリの処理と組み合わせる

共通UIは表示や操作だけを担当します。フォームは入力が有効なら通常のsubmitを続けます。保存・送信先・通信・ページ遷移はアプリ側で指定してください。カンバンの移動はページ内のDOMのみを更新します。

ui:valid（キャンセル可能）、ui:tabchange、ui:pagechange、ui:move、ui:shown、ui:hiddenのイベントでアプリの処理を接続できます。

document.addEventListener('ui:valid', event => {
  // 通常のフォーム送信を止め、自分の保存処理を呼びます。
  event.preventDefault();
  const values = new FormData(event.target);
  // saveProject(values);
});

document.addEventListener('ui:move', event => {
  const { card, from, to } = event.detail;
  // persistMove(card.dataset.uiCard, from, to);
});

KavUI.toast({
  title: '保存しました',
  body: 'プロジェクトの変更を保存しました。',
  meta: 'たった今',
  variant: 'success'
});
// 従来の文字列形式も利用できます。
KavUI.toast('保存しました。', { variant: 'success' });
KavUI.show('#my-dialog');
KavUI.hide('#help-panel');

// 動的に追加したHTMLのARIA・初期表示を整える場合：
KavUI.init(container);

initは繰り返し実行できます。操作のイベントは委譲しているため、後から追加したボタンも動作します。

カタログ固有のファイル

catalog.css / layout.css / catalog.js / catalog-navigation.js / catalog-demo.js と Flexbox playground は見本画面専用です。アプリでは ui.css / ui.js を使ってください。HTMLのdata-demo-*は送信を止めたり結果を模擬表示するための属性です。アプリに取り込む際は外してください。カタログではdata-example内のリンクによるページ移動と通常のフォーム送信を止めています。メニューやタブの切り替え、入力検証、ダイアログの確定は試せます。コピー用HTMLのhrefやactionはそのままなので、アプリでは通常どおり動作します。
